Task Manager - MERN App

Aplicación web para crear, gestionar y organizar tareas de manera sencilla, desarrollada con la metodología MERN (MongoDB, Express.js, React, Node.js) y desplegada en Oracle Cloud utilizando Rocky Linux.

Características

 CRUD completo: Crear, leer, actualizar y eliminar tareas.

 Interfaz simple e intuitiva para gestionar pendientes.

 Despliegue en la nube usando Oracle Cloud + Rocky Linux.

 API REST segura con manejo de errores y validaciones.

 Tecnologías utilizadas

Frontend: React

Backend: Node.js + Express.js

Base de Datos: MongoDB 

Cloud Provider: Oracle Cloud (OCI)

OS de despliegue: Rocky Linux 9

Control de versiones: Git + GitHub
